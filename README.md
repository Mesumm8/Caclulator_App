# 🧮 JavaScript Web Calculator

A feature-rich, dynamic web-based calculator application built with **Vanilla JavaScript**, **HTML5**, and **CSS3**. It supports basic arithmetic operations, expression evaluation, backspace handling, chained result calculations, percentage conversions, and sign negation.

---

## ✨ Features

* **Real-time Expression Display:** Live updating of current mathematical expressions and calculated results.
* **Basic & Advanced Operations:** Supports addition, subtraction, multiplication, division, decimal points, and percentages (`%`).
* **Result Chaining:** Seamlessly start a new operation using the previous result as the starting value.
* **Sign Negation:** Quickly toggle positive and negative signs (`+/-`) for active expressions or saved results.
* **Smart Decimal & Operator Validation:** Prevents invalid duplicate operators or multiple decimal points within a single number.
* **Error Handling & Floating-Point Precision:** Safely handles division by zero (`Infinity`/`NaN`) and rounds float numbers for clean display.

---

## 🛠️ Tech Stack

* **Structure:** HTML5 (DOM event delegation using `dataset` attributes)
* **Logic:** Vanilla JavaScript (ES6+)
* **Styling:** CSS3
